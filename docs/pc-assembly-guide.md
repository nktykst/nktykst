# 自作PC 組み立てガイド（Ryzen 7 9700X / RTX 5060 Ti / Ubuntu）

作成日: 2026-09-22
対象: 自作初めての人向け。各メーカーの公式マニュアル・仕様ページ・FAQをもとに、この構成専用の手順にまとめたもの。

> **調べ方についての注意**
> 作業環境のネットワーク制限で、ASUS / Corsair / MSI / AMD / NVIDIA / Team Group / Kioxia の公式ページや PDF を直接開くことができなかった。
> ここに書いた内容は、公式ページ・公式マニュアルの検索結果抜粋、および信頼できるレビュー記事から組み立てている。
> **「要確認」と書いた項目は、箱に入っている紙のマニュアルか、下のリンク先 PDF で必ず確認してから作業すること。**
> Ubuntu 関連は公式ドキュメントを直接確認できたので信頼度が高い。

### 最初に知っておくべき重要ポイント

1. **簡易水冷は天面（トップ）に付ける。** MSI 公式仕様では前面は 240mm までで、360mm は天面のみ対応。天面に付けるとメモリ上空に約52mm（ラジエーター27mm＋ファン25mm）がかぶさる。メモリのヒートスプレッダが高い DELTA RGB 系（約46mm）だと干渉の可能性があるので、ネジ止め前に必ず仮合わせする。VULCAN 系（約33mm）なら余裕がある見込み。
2. **CPU は「置くだけ」。** AM5 はソケット側にピンがある。CPU を斜めに入れたり押し込んだりしない。黒いカバーはレバーを閉じると勝手に外れる。
3. **GPU の補助電源コネクタは買ったカードによって違う。** 8ピンなら電源付属の PCIe 6+2 ケーブル、16ピン（12V-2x6）なら電源付属の 12V-2x6 ケーブルを使い、**「カチッ」と鳴るまで奥まで挿してすき間がないことを確認**する。
4. **電源ケーブルは RM850x の箱に入っているものだけ使う。** 他社・他シリーズのケーブルは形が合っても配線が違い、パーツを壊すことがある（Corsair 公式の警告）。
5. **初回起動はメモリトレーニングで 1〜3 分画面が出ないことがある。** 故障ではないので待つ。
6. **OS は Ubuntu 26.04.1 LTS を推奨。** RTX 50 系は NVIDIA の「open」ドライバ（`nvidia-driver-580-open` 以降、26.04 なら 595-open）が必要で、26.04 ならインストーラーから自動で入る。

### 作業の全体像（この順番で進める）

1. ケースの外で、マザーボードに CPU・メモリ・SSD を載せる
2. 簡易水冷の AMD 用ブラケット準備と、ポンプヘッドの取り付け
3. ケースの準備（パネル外し、スタンドオフ確認、I/O パネル）
4. マザーボードをケースに入れる
5. ラジエーターを天面に取り付ける
6. 電源の取り付けと配線
7. フロントパネル・ケースファン・ARGB 基板の配線
8. GPU の取り付け
9. 配線整理、パネルを閉じる
10. 初回起動と BIOS 設定
11. Ubuntu インストールと NVIDIA ドライバ

## 2. マザーボードにパーツを載せる（ケースの外で）

マザーボードを箱の上に置き、まず全体を眺めて以下の位置を確認する（マニュアルの「Motherboard layout」ページ。**位置は要確認**）。

- CPU ソケット（中央上）と、その周りの 2 本の黒い樹脂製クーラー固定ブラケット
- DIMM スロット 4 本（ソケット右）: 左から DIMM_A1, A2, B1, B2
- M.2_1（ソケット下、GPU スロットの上）: ヒートシンク付き、PCIe 5.0
- ファンヘッダー: CPU_FAN, CPU_OPT, AIO_PUMP（ソケット上あたり）、CHA_FAN1〜4
- ADD_GEN2（5V 3ピン ARGB）ヘッダー ×3
- 24 ピン電源（右端）、8+4 ピン CPU 電源（左上）
- 右下: PANEL（フロントパネル）、USB 19 ピン、USB 2.0、左下: AAFP（フロント音声）
- Q-LED（CPU / DRAM / VGA / BOOT の 4 つの LED、24 ピンの近く）

### 2-1. CPU の取り付け（AMD / ASUS の手順）

1. ソケット横のレバーを下に押しながら外側にずらして外し、上まで起こす。金属の押さえ板（ロードプレート）が開く。
2. **黒い樹脂カバーはまだ外さない。**
3. CPU を袋から出す。裏面（接点側）に触れない。CPU の角にある小さな**金色の三角**と、ソケット角の三角マークを合わせる。
4. CPU を真上からそっと置く。向きが合っていれば自重で収まる。**絶対に押さない。** 収まらないなら向きが違うので持ち上げてやり直す。
5. ロードプレートを閉じ、レバーを下ろしてフックに掛ける。少し重いが正常。このとき黒いカバーが**自動的に外れる**。カバーは保証対応用に取っておく。

### 2-2. メモリの取り付け

1. **DIMM_A2 と DIMM_B2**（CPU から数えて 2 番目と 4 番目）を使う。ASUS の AM5 マザーはこの配置が標準（このマニュアルの表は要確認）。
2. スロットの爪を開く（ASUS Q-DIMM は片側だけ爪がある場合がある）。
3. メモリの切り欠きとスロットの出っ張りを合わせ、両端を親指で**かなり強く**均等に押し込む。「カチッ」と爪が起きて固定されたら完了。挿しが甘いと起動しないので、上から見て両端が同じ高さになっているか確認する。

### 2-3. M.2 SSD の取り付け

1. **M.2_1**（CPU 直結、PCIe 5.0 x4、ヒートシンク付き）を使う。Gen4 の SSD でも Gen5 の SSD でもこのスロットが最速。
2. ヒートシンクのネジを外してヒートシンクを取り、裏面のサーマルパッドに保護フィルムがあれば剥がす。
3. スロットに SSD を約 30 度の角度で差し込み、寝かせる。
4. 固定は **M.2 Q-Latch**（ネジ不要の回転ラッチ）が付いているスロットならラッチを回して固定、無ければ付属のネジで固定する（どのスロットが Q-Latch かは要確認）。
5. ヒートシンクを戻してネジ止めする。付属の「M.2 ラバーパッド」は、片面実装 SSD の裏面用に必要なら貼る。

### 2-4. 簡易水冷のポンプ側の準備（まだケースに入れる前）

Nautilus 360 RS のクイックスタートによる AMD AM5 手順。

1. ポンプヘッドに最初から付いている **Intel 用ブラケット (A) をスライドして外し、AMD 用ブラケット (D) をはめる**。
2. マザーボードのソケット両脇にある**黒い樹脂ブラケット 2 本を、ネジ 4 本を外して取り外す**。裏側の金属バックプレートは**そのまま**（マザーに固定されていて外せない。これを使う）。
3. バックプレートのネジ穴 4 か所に、**AMD 用スタンドオフ (E) 4 本**をねじ込む。手で締めた後、軽く増し締めする。
4. ポンプ底面の保護カバーを外す（グリス塗布済みなので、触らない・拭かない）。
5. ポンプヘッドをスタンドオフ 4 本の上に載せ、**サムナット (F) を対角線順に**少しずつ締める。最後に 4 か所が均等に締まっていれば完了。

ポンプヘッドの向き（要確認）: 非 RGB 版はキャップが回らないため、ロゴが正しく読める向きにするとチューブがメモリ側（右）に出る。チューブは根元が回るので、後でラジエーターに向けて曲げられる。

> **やっておくとよい: ケース外での「最小構成テスト」**
> この時点でマザー・CPU・メモリ・SSD・ポンプが載っている。電源の 24 ピンと 8 ピン CPU 電源、ポンプとファンのケーブルを仮接続し、モニターをマザーの HDMI/DP につなぎ、PANEL ヘッダーの PWR SW 2 ピンをドライバーの先で一瞬短絡させると起動する。ラジエーターは箱の上に置いておけばよい。
> 画面に ASUS のロゴ → BIOS 画面（Del キー）が出れば、ケースに入れる前に基本動作が確認できる。初回はメモリトレーニングで最大数分待つ。
> やらなくてもよいが、初めてなら原因切り分けが圧倒的に楽になる。

## 3. ケースの準備

MSI のユーザーガイド（p.13〜）による。

1. **左側の強化ガラスパネル**: 背面の手回しネジを緩め、パネルを後ろにスライドして持ち上げて外す。ガラスは柔らかい布の上に寝かせる。
2. **右側（裏配線側）の金属パネル**: 同様に背面の手回しネジを緩めて外す。
3. **天面のマグネット式フィルター**を外す。ラジエーターを天面に付けるので、天面のファン取り付け穴が見える状態にする。
4. 前面メッシュパネルは、下端をつかんで手前に引くと外れる。今回は前面にラジエーターを付けないので基本的に外さなくてよい。
5. **スタンドオフの確認**: ATX 用のスタンドオフが最初から付いている。PRIME B850-PLUS の 9 か所のネジ穴に対応する位置にあるか、マザーをかざして確認する。足りなければ付属の #6-32 スタンドオフを追加する。**穴が無い位置にスタンドオフがあると基板裏でショートするので必ず取り除く。**
6. **I/O パネル（バックパネルのシールド）**: マザーボードに一体型で付いていればそのまま。別体で袋に入っていれば、ケース内側から背面の四角い穴にはめ込む（4 辺がカチッと収まるまで押す）。PRIME B850-PLUS がどちらかは要確認（近年の ASUS PRIME は一体型が多い）。
7. HDD ケージ（電源シュラウド内）は今回使わないので、電源の作業がしやすいよう外してもよい（#6-32 10mm ネジ 2 本）。

## 4. マザーボードをケースに入れる

1. ケースを横に寝かせる（左側面が上）。
2. マザーボードを斜めに入れ、まず背面の I/O ポートが I/O パネルの穴に合うように押し当てながら、ネジ穴をスタンドオフに合わせる。
3. 付属の **M3 5mm ネジ**で 9 か所を止める。まず対角 2 本を軽く仮止め → 全部入れてから順に締める。締めすぎない（基板がたわまない程度）。
4. 天面ラジエーター取り付け前に、この段階で **CPU 8 ピン電源のヘッダー（左上）の位置**を確認しておく。ラジエーターが付くとここが狭くなるので、先にケーブルを差しておくと楽（電源の取り付け後でもよい）。

---

## 5. ラジエーターを天面に取り付ける

1. **ファン 3 個をラジエーターにネジ止め**（長いネジ (G)）。向き: ファンは**ラジエーターの下側（ケース内側）**に付け、風がラジエーターを通ってケースの上へ抜ける向き（排気）にする。ファンの側面にある矢印が風向きで、上（天面）に向くようにする。ファンの表（羽根が見える側）が下、フレーム側の枠（ケーブルが出る側）が上向きになる。
2. **配線は先に**: 3 個のファンはデイジーチェーン（1 個目の 4 ピンプラグを 2 個目の受け口に、2 個目を 3 個目に）。最後の 1 本が余るので、付属の PWM 延長ケーブル (K) をつなぐ。ARGB 版の場合は ARGB ケーブルも同じように数珠つなぎにする。
3. チューブの位置決め: 実際にケース内でラジエーターを天面に当ててみて、チューブがポンプヘッドまで無理なく届く側（通常は前面寄り、メモリ側）を選ぶ。**チューブを強く曲げたり、ねじったりしない。**
4. **仮合わせ**: ラジエーター＋ファン（約 52mm 厚）が、メモリの上端・VRM ヒートシンク・8 ピン CPU 電源ケーブルに当たらないか確認。当たる場合は、ファンをラジエーターの上（天面側）に付け直す構成が可能かケースの天面を見て検討する（**天面のスペースは要確認**）。
5. 天面の外側から、**短いネジ (H) ＋ ワッシャー (I)** でラジエーターを固定する（ファン越しではなくラジエーターのねじ穴に直接）。ケースの天面のスロット穴を使い、前後位置を調整しながら 8 本程度で止める。
6. Corsair の推奨: ラジエーターがポンプより高い位置にある（天面取り付けは自然にこれを満たす）。**ポンプがループの最高点にならない**ようにする。

## 6. 電源の取り付けと配線

### 6-1. 先にケーブルを電源に挿す

RM850x（2024）はフルモジュラーなので、**ケースに入れる前に必要なケーブルを電源本体に差しておく**。使うのは以下だけ。

| ケーブル | 本数 | 行き先 |
|---|---|---|
| ATX 24 ピン（20+4） | 1 | マザー右端の 24 ピン |
| EPS 8 ピン（4+4） | 1（必要なら 2） | マザー左上の 8 ピン CPU 電源。隣の 4 ピンは 65W の 9700X なら未接続でも動くが、2 本目の EPS ケーブルの 4 ピン側を挿してもよい |
| PCIe 6+2 ピン **または** 12V-2x6（16 ピン） | 1 | GPU（カードのコネクタに合わせて**どちらか一方**） |
| SATA 電源 | 1 | ケースの ARGB コントロール基板 |

電源側は、ケーブルの根元のロックがカチッと掛かるまで奥まで挿す。**他の電源のケーブルは絶対に混ぜない。**

### 6-2. 電源をケースに入れる

1. 電源のファンが**下向き**（ケース底面の吸気口・スライド式フィルター側）になる向きで、電源シュラウド内に側面から滑り込ませる。
2. 背面から付属の **#6-32 6mm ネジ 4 本**で固定する。
3. 背面の電源スイッチは **O（オフ）**のままにしておく。背面のファン調整ノブは初期位置（反時計回りいっぱい = Zero RPM モード、低負荷ではファンが回らない）のままでよい。

### 6-3. マザーボードへの配線

裏配線側（右側面）にケーブルを通し、マザー右側の穴から表に出す。

1. **24 ピン**: マザー右端。ロック爪の向きを合わせて、かなり強く押し込む。カチッと鳴って、隙間なく入っていることを確認。
2. **8 ピン CPU 電源**: 左上。ラジエーターの下で狭いので、ラジエーター固定前に挿しておくと楽。
3. **ポンプ**: ポンプヘッドから出ている 4 ピンを **AIO_PUMP** ヘッダーに挿す（ASUS の推奨。AIO_PUMP はデフォルトで常時フル回転なのでポンプに最適）。Corsair の推奨は CPU_FAN だが、どちらでも動く。
4. **ラジエーターファン**: 延長ケーブルの先を **CPU_FAN** に挿す。これで BIOS が「CPU ファン未接続」エラーを出さず、ファン回転数が CPU 温度に連動する。
5. **ARGB 版の場合**: ポンプから出ている ARGB ケーブルを、付属の ARGB 延長ケーブルで **ADD_GEN2** ヘッダー（5V 3 ピン）に挿す。3 ピン側の向きに注意（5V の印字を合わせる）。12V 4 ピンの RGB ヘッダーには絶対に挿さない。

## 7. フロントパネル・ケースファン・ARGB 基板の配線

ケースから出ているケーブルをすべてマザーにつなぐ。MSI のユーザーガイド「Front Panel Connectors」「Control Board Connection」による。

| ケースのケーブル | マザーのヘッダー | メモ |
|---|---|---|
| F_PANEL（一体型ブロック） | **PANEL**（右下、10-1 ピン） | MSI の「uni front panel cable」はブロック一体型。ASUS PANEL の並びは上段: PLED+ / PLED- / PWRSW、下段: HDD_LED+ / HDD_LED- / RESET。ブロックがそのまま合うか、合わなければブロックを分解して 1 本ずつ挿す（要確認）。スイッチ類は極性なし、LED は極性あり（逆でも壊れないが光らない）。 |
| USB 3.0 19 ピン（JUSB） | USB 5Gbps 19 ピンヘッダー | 前面 USB-A ×2 用。切り欠きの向きに注意、力を入れすぎるとピンが曲がる。 |
| HD AUDIO（JAUD1） | **AAFP**（左下） | 前面イヤホン・マイク用。 |
| ケースファン 4 個 → 付属の 1-to-4 分岐ケーブル | **CHA_FAN1**（または任意の CHA_FAN） | 分岐ケーブルの先を 1 つのヘッダーへ。1A/12W の範囲内。ファンのモーター側が 4 ピン PWM か 3 ピン DC かは要確認。 |
| ARGB コントロール基板の SATA 電源 | 電源の SATA ケーブル | 基板の電源。 |
| ARGB コントロール基板の M/B ケーブル | **ADD_GEN2**（5V 3 ピン） | マザー側で光を制御したい場合。フロントの LED ボタンを**3 秒長押し**でマザー同期モードに切り替わる。Ubuntu では ASUS の制御ソフトが無いので、基本は基板側のボタンで色を変える運用になる（OpenRGB で制御できる場合もある）。 |

ケースの 320R は前面に USB-C が無い。マザーの USB-C フロントヘッダーは未使用でよい。

## 8. GPU の取り付け

1. ケース背面の拡張スロットカバーのうち、**PCIEX16(G5)**（CPU に一番近い x16、補強付き）の高さに当たるカバーを外す。2 スロット厚のカードなら 2 枚、2.5〜3 スロット厚なら 3 枚。
2. 静電気に注意してカードを取り出す。端子の保護キャップを外す。
3. スロットの **Q-Release** レバーは、挿すときは操作不要。カードの端子をスロットに合わせ、**カチッとロックが掛かるまで**まっすぐ押し込む。背面のブラケットが背面パネルに密着する。
4. ブラケットを **#6-32 6mm ネジ**で固定する。
5. 補助電源を挿す。**カードの上端を見る**:
   - 黒い **8 ピン（2×4）**なら、電源の PCIe 6+2 ケーブルを 1 本。6+2 の 2 ピン部分をきちんと合体させてから挿す。
   - 小さな **16 ピン（12V-2x6 / 12VHPWR）**なら、**RM850x 付属の 12V-2x6 ケーブル**を使う。カード付属の 2×8→16 ピン変換は使わなくてよい。奥まで押し込んで**カチッ**、コネクタとカードの間に**すき間がない**ことを目視。コネクタの根元でケーブルを急に曲げない（根元から 3cm 程度はまっすぐ）。
6. 外すときは、Q-Release を押しながらカードの背面側を持ち、少し斜めにして引き上げる（ASUS FAQ 1047530）。

このケースは GPU 390mm まで対応なので、どのメーカーの RTX 5060 Ti でも長さは問題ない。

## 9. 配線整理とパネル

1. 裏配線側で、ケーブルを付属の結束バンドでタイダウンポイントに留める。裏側の深さは約 2〜3cm しかないので、太い 24 ピンは中央の溝に沿わせる。
2. 表側で、ファンやポンプのケーブルが**ファンの羽根に当たらない**ことを確認する。
3. 使っていない電源ケーブルの端（SATA の余りなど）は結束して固定する。
4. ケース内に落ちたネジや工具が無いか確認する。
5. まだパネルは閉めず、初回起動を先に行う。

## 10. 初回起動と BIOS 設定

### 10-1. 接続と電源投入

1. モニターケーブルを **GPU の出力**（マザーの HDMI/DP ではなく）に接続する。
2. キーボード・マウスを背面 USB に接続する。
3. 電源ケーブルを差し、背面スイッチを **I（オン）**にする。
4. ケース前面の電源ボタンを押す。ファンが回り、Q-LED が順に点灯して消える。**初回はメモリトレーニングで 1〜3 分画面が出ないことがある。**
5. ASUS ロゴが出たら **Del キー**連打で BIOS（UEFI）に入る。

### 10-2. 起動しない場合（Q-LED で切り分け）

| 点灯したまま | 意味 | 確認すること |
|---|---|---|
| CPU（赤） | CPU 未検出 | 8 ピン CPU 電源、CPU の向き、ポンプの締めすぎ・緩み |
| DRAM（黄） | メモリ | A2/B2 に入っているか、両端まで挿さっているか。1 枚だけにして試す |
| VGA（白） | GPU | 補助電源、スロットに完全に入っているか。マザーの HDMI に挿し替えて内蔵 GPU で表示できるか |
| BOOT（黄緑） | 起動デバイス無し | この段階では正常（OS がまだ無い） |

まったく反応が無い: 電源スイッチ、24 ピン、PANEL ヘッダーの PWR SW 位置を確認。

### 10-3. BIOS でやること

1. **EZ Mode の画面で確認**: CPU 名が Ryzen 7 9700X、メモリ 32GB（速度は最初 4800 か 5600 表示）、ストレージに Kioxia が見える、CPU 温度が 30〜50 ℃台、ファン回転数が表示されている。
2. **EXPO 有効化**（ASUS FAQ 1042256）: F7 で Advanced Mode → Ai Tweaker → Ai Overclock Tuner → **EXPO I** を選ぶ。メモリが XMP のみのキットの場合は選択肢に XMP が出るのでそれを選ぶ。F10 で保存して再起動。再起動でまた数分のトレーニングが入ることがある。**起動しなくなったら**、電源を切って 30 秒待ち、再度電源を入れると自動で安全設定に戻る（ダメなら CMOS クリア）。
3. **ファン設定**: Q-Fan Control で、AIO_PUMP が Full Speed（初期値）、CPU_FAN と CHA_FAN が PWM モードになっているか確認。静かにしたければ CHA_FAN のカーブを Silent に。
4. **BIOS 更新**（推奨）: 9700X は初期 BIOS で動くが、メモリ安定性や不具合修正が入っている。もう 1 台の PC で https://www.asus.com/motherboards-components/motherboards/prime/prime-b850-plus/helpdesk_bios?model2Name=PRIME-B850-PLUS から最新版をダウンロードし、FAT32 の USB メモリに入れて BIOS の **EZ Flash 3** から更新する。
   - 起動できない場合の最終手段: **BIOS FlashBack**。ダウンロードした ZIP 内の BIOSRenamer.exe で **A5659.CAP** にリネームし、USB のルートに置き、背面の「BIOS」表示のある USB ポートに挿し、電源スタンバイ状態で FlashBack ボタンを 3 秒押す。LED が点滅→消灯（最長 8 分）で完了。CPU/メモリ無しでも実行できる。
5. **Secure Boot**: Ubuntu は Secure Boot 有効でもインストールできる（Ubuntu が用意した署名済み NVIDIA ドライバが使える）。迷ったら**そのまま（有効）**でよい。
6. **CSM は無効（UEFI モード）**のまま。

## 11. Ubuntu のインストール

### 11-1. バージョンの選択

- **Ubuntu 26.04.1 LTS**（2026-08-27 リリース、カーネル 7.0、NVIDIA 580/590/595 収録）を推奨。Zen 5 と RTX 50 系（Blackwell）が最初から対応済み。
- 24.04.4 LTS でも動くが、HWE カーネルと `nvidia-driver-580-open` 以降が必要になる。

### 11-2. インストール USB の作成

1. https://ubuntu.com/download/desktop から ISO をダウンロード。
2. Windows なら **Rufus**（パーティション構成 GPT、ターゲット UEFI、ISO モードで書き込み）、mac なら **balenaEtcher**。8GB 以上（16GB 推奨）の USB メモリを使う。公式手順: https://ubuntu.com/desktop/docs/en/latest/how-to/create-a-bootable-usb-stick/

### 11-3. インストール

1. USB を挿して電源投入、ASUS ロゴで **F8** を連打してブートメニューから **UEFI: (USB メモリ名)** を選ぶ。
2. GRUB で「Try or Install Ubuntu」を選ぶ。**画面が真っ黒のままなら**: 一度電源を切り、モニターケーブルをマザーの HDMI/DP（内蔵 GPU）に挿し替えて起動し、GRUB で「Ubuntu (safe graphics)」を選ぶ。
3. インストーラーで、**「グラフィックスや Wi-Fi ハードウェア用のサードパーティ製ソフトウェアをインストール」（Install third-party software...）にチェック**を入れる。有線 LAN（Realtek 2.5G、カーネル標準の r8169 ドライバで動く）をつないでおく。これで NVIDIA の open ドライバが自動で入る。
4. ディスクは Kioxia の NVMe を選び「ディスクを削除して Ubuntu をインストール」。他のディスクは無いので消えて困るものは無い。
5. 完了後、USB を抜いて再起動。GPU 側にモニターを戻す。

### 11-4. インストール後の確認

```bash
# NVIDIA ドライバが入っているか（RTX 5060 Ti と 595 系が表示されれば OK）
nvidia-smi

# 入っていなければ
sudo ubuntu-drivers list
sudo ubuntu-drivers install          # 推奨（open 版が自動選択される）
# または明示的に
sudo ubuntu-drivers install nvidia:595
sudo reboot

# CPU の省電力ドライバ（amd-pstate-epp と出れば OK）
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_driver

# 有線 LAN（driver in use: r8169 と出れば OK）
lspci -k | grep -A3 Ethernet

# SSD の健康状態（Kioxia の SSD Utility は Windows 専用なので Linux ではこれを使う）
sudo apt install nvme-cli smartmontools
sudo nvme list
sudo smartctl -a /dev/nvme0

# メモリが 6000 で動いているか
sudo dmidecode -t memory | grep -i "configured memory speed"

# 温度（lm-sensors）
sudo apt install lm-sensors && sudo sensors-detect --auto && sensors
```

Secure Boot 有効で DKMS 版ドライバを入れた場合だけ、再起動時に青い「Perform MOK management」画面が出る。**Enroll MOK → Continue → Yes → 設定したパスワード入力 → 再起動**で完了。Ubuntu 標準の署名済みドライバ（`ubuntu-drivers install` で入るもの）ならこの画面は出ない。

## 12. 動作確認とチェックリスト

- [ ] アイドル時 CPU 温度 40〜50 ℃台、負荷時 80 ℃未満（`sensors` で確認）。高い場合はポンプが AIO_PUMP で回っているか（BIOS で回転数を確認）、グリス面に保護フィルムが残っていないか。
- [ ] `nvidia-smi` で GPU が見える。
- [ ] メモリが 6000 MT/s で動いている。不安定（フリーズ・再起動）なら BIOS で EXPO を切って様子を見る。
- [ ] 前面 USB・音声ジャックが使える。
- [ ] ケースの LED ボタンで色が変わる。
- [ ] 電源のファンが低負荷で止まっているのは正常（Zero RPM モード）。
